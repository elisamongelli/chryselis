/api/schemas contains one file for each entity
-stanza.py: defines entity serialization with classes for automatic mapping with the room model
-stato.py: defines entity serialization with classes for automatic mapping with the status model
-programma.py: defines entity serialization with classes for automatic mapping with the schedule model
-pianta_programma.py: defines entity serialization with classes for automatic mapping with the plant-schedule association model
-pianta.py: defines entity serialization with classes for automatic mapping with the plant model
-pianta_storico.py: defines entity serialization with classes for automatic mapping with the plants history model
